## 三、两处自我辩护的专门裁定

### B1「不引入 yaml 依赖」——**取舍不成立，但理由比双方说的更微妙**

开发团队理由："保持零依赖是本项目卖点"。

**我的裁定：理由成立，但结论错了——正确解法既不是"引依赖"也不是"手写解析器"。**

- 蓝军建议「引入 yaml 依赖」**同样不可取**：它会让 `node scripts/validate-skill.mjs` 需要 `npm install` 才能跑，破坏 clone-and-run，与 SKILL.md:85「本仓库自带校验器，无需安装依赖」直接冲突。
- 但"零依赖"**不能成为手写 YAML 解析器的正当性**。实测证据：
  - 该解析器**已经出过一次块标量缺陷**（B1，蓝军发现）；
  - **`09a2135` 又出第二次**（folded/literal 语义完整对调，见下）；
  - 8 个突变全部逃逸（§一·T5）。
- **用户侧的后果是致命的**：这个校验器的用户是**写 skill 的人**，他们不会二次核对，看到 `✅ 通过` 就发布。一次误报"通过"就传播一次错误——这与 SKILL.md:19 自己点名的第一类风险（"用未验证的乐观假设说服自己推迟修复"）同构。
- **正确解法**：① **限定输入契约**——校验器只需处理 SKILL.md frontmatter 的子集，应在文档中明确"本校验器不是通用 YAML 解析器，不支持锚点/多文档/流式集合"，遇到不支持语法时**报错退出而非静默降级**；② 对**块标量这一唯一复杂点**用显式状态机 + 表驱动测试，而非正则拼接；③ 保留 `compatibility` 降级说明。

**结论：开发团队守住了"零依赖"这个正确的目标，却用了一个与目标不匹配的实现手段，并且这个手段已经连续失败两次。**

## 四、实质分歧：**两方都没说对的地方**

### 分歧 1：T2 的哈希证据 —— **第三方错，但它得出了对的结论**

第三方给出的命令 `git show 4637e50:references/skill-spec.md` **指错了路径**，且在 `4637e50` 下该文件位于**仓库根目录**（v1.1 尚无 `skills/` 布局）。我的实测：
```
git show 4637e50:skills/adversarial-review/references/skill-spec.md
  → fatal: path ... exists on disk, but not in '4637e50'
  → 空 blob e69de29bb2d1d6434b8b29ae775ad8c2e48c5391
git show 4637e50:references/skill-spec.md | git hash-object --stdin
  → 7a21fd8dcc5d3bd6fb412c2421957cfa2944d9ed   ← 与 HEAD 相同
git diff --stat 4637e50..bfb58ee  → 该文件 0 insertions, 0 deletions
```
**正确表述**：这不是"两个哈希相同"，而是"**该文件从未被修改，只是被 `git mv` 重命名**"。第三方用"哈希相同"作证据，会被反驳为"文件没动当然哈希相同，这不能证明你声称的内容"；而"0 行改动 + 内容中确无该约束"才是不可反驳的。

**裁定：结论采纳，证据链驳回，定级由 🔴 下调为 🟠（且应标注"已自行作废"）。**

### 分歧 2：**`09a2135` 是一次失败的修复 —— 这是本轮最严重的发现，两方均未察觉**

因为两方都在"整改前"或"整改中"工作，**没有任何一方审查过 `09a2135`**。我在 `git archive 09a2135` 的隔离副本上运行其自带测试：

```
结果: 17 通过, 3 失败
  ✗ 折叠块结果应以空格连接，不含换行符
      折叠块不应含 \n，实际: "line one here\nline two here"
  ✗ 字面块结果应保留换行符
      字面块应含 \n，实际: "line one here line two here"
  ✗ 块标量之后紧跟另一个块标量，状态不应残留
      description 应是折叠块（不含 \n），实际 "folded one\nfolded two"
```

根因（我直接读代码）：`validate-skill.mjs:74` 的分支条件被改为 `if (blockStyle === "literal")`，但**该分支体仍是空格拼接、注释仍写"折叠块"**。结果是：
- `>` 折叠块 → 走 else 分支 → **换行连接**（应为空格）
- `|` 字面块 → 走 if 分支 → **空格连接**（应为换行）

**folded 与 literal 语义被完整对调，即 B1 的缺陷在 v2.0.1 以镜像形式复发。**

**为什么能溜过**：① 字符数断言（T5 的盲区）**全绿**——同一内容下 111==111；② 新增的内容断言虽写对了语义，但**提交时未跑**（工作区版本后来被改成正确实现，说明作者事后发现，但**已提交的 `09a2135` 从未回修**）。

> **这构成对 T5 的最终裁定：T5 的定级应从 🟡 上调至 🟠。它不再是一个"可能"的风险，而是一个已经使真实回归逃逸检测的既成事实。**

蓝军把"v1.1 首发时换行符是坏的，已在 `4637e50` 修复"列为 🟡 待办。这是**已闭合的历史事件**。裁定：**驳回成立**，且蓝军此处存在方法错误——把修复记录当作未决缺陷，会让清单失去"下一步该做什么"的功能。
